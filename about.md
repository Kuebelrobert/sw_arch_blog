I write software for embedded systems and use this blog to collect what I've learned — from day-to-day project work and from digging into topics on my own time.

Topics I cover here include:

- **Security** — secure boot, key management, threat modeling for embedded products
- **Flashing** — bootloaders, update mechanisms, A/B update strategies
- **Communication** — CAN, LIN, SPI, UART, diagnostics protocols
- **RTOS** — task design, scheduling, real-world lessons from FreeRTOS/Zephyr and others
- **AutoSAR** — practical concepts for developers coming from bare-metal or RTOS backgrounds
- **Firmware** — architecture patterns, portability, low-level design decisions
- **Debugging** — JTAG/SWD workflows, tracking down hard-to-reproduce bugs
- **AI** — where AI tooling actually helps in embedded/firmware engineering
- **Engineering Processes** — code review, branching, release practices for firmware teams

This is a personal, ongoing project — posts get revised as I learn more.
